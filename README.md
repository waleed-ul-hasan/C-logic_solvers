# 🧩 C-Language Logic Solvers
This repository contains a collection of programs written in **C** to solve mathematical puzzles and track academic progress.

### 🚀 Projects Included:
1. **Grade & Percentage Calculator:** A tool to calculate academic performance.
2. **Number Logic Solver:** (Coming soon) A script to solve quantitative reasoning puzzles.

### 🛠️ How to Run:
These programs are written in Standard C. You can compile them using any C compiler (like GCC or Clang) or run them in **GitHub Codespaces**.
